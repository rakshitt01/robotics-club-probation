# robotics-club-probation

A beginner-friendly repository created as part of the Robotics Club probation task to learn and demonstrate basic Git and GitHub workflows, including repository creation, commits, branching, forking, cloning, pushing changes, and creating pull requests.## Project Purpose



This repository is created for Robotics Club probation.



The purpose is to learn Git and GitHub fundamentals,

including repository creation, commits, branching and collaboration.
